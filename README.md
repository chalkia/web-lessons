# Πλατφόρμα εξ αποστάσεως ιδιαιτέρων

Στατική ιστοσελίδα (GitHub Pages) με βάση και είσοδο χρηστών στο Supabase.

## Τι κάνει η πρώτη έκδοση

- **Είδη λογαριασμού:** διαχειριστής, εκπαιδευτικός, μαθητής/γονέας. Ο καθένας διαλέγει στην εγγραφή «Εκπαιδευτικός» ή «Μαθητής ή γονέας».
- **Σχέσεις ανά μαθητή:** ο γονέας και ο βοηθός δεν είναι είδη λογαριασμού. Είναι σχέσεις με συγκεκριμένο μαθητή. Ο ίδιος εκπαιδευτικός έχει δικούς του μαθητές και ταυτόχρονα είναι βοηθός σε μαθητές άλλων.
- **Μαθητές:** ο εκπαιδευτικός προσκαλεί μαθητές, τους συνδέει με γονείς και καλεί άλλους εκπαιδευτικούς ως βοηθούς.
- **Ημερολόγιο / παρουσιολόγιο:** προγραμματισμένες ώρες, πραγματοποιημένες, απουσίες, ακυρώσεις. Κάθε χρήστης βλέπει μόνο ό,τι τον αφορά.
- **Βιντεοκλήση:** ο εκπαιδευτικός βάζει σύνδεσμο (Meet, Zoom, Jitsi) σε κάθε μάθημα. Η αρχική σελίδα δείχνει το κουμπί «Είσοδος στο μάθημα».
- **Προσωπικό ημερολόγιο:** οι επόμενες υποχρεώσεις κάθε χρήστη.
- **Διαχειριστής:** βλέπει τα πάντα και αλλάζει το είδος λογαριασμού.

## Για την επόμενη φάση

- Σημειώσεις στο cloud (Supabase Storage) με πρόσβαση ανά μαθητή και βοηθό.
- Περιεχόμενο H5P μέσα στον χώρο του εκπαιδευτικού.

## Εγκατάσταση

### 1. Supabase

1. Φτιάξε project στο [supabase.com](https://supabase.com).
2. Άνοιξε **SQL Editor**, επικόλλησε ΟΛΟ το `supabase/schema.sql` και πάτα Run.
3. Στο **Project Settings > API** αντίγραψε το *Project URL* και το *anon public key*.
4. Βάλ' τα στο `js/config.js`.
5. Στο **Authentication > URL Configuration** βάλε ως Site URL τη διεύθυνση του GitHub Pages (βήμα 3).

Μην βάλεις ποτέ το κλειδί `service_role` στο `config.js`.

### 2. Πρώτος διαχειριστής

1. Άνοιξε την εφαρμογή και κάνε εγγραφή με το email σου.
2. Στο SQL Editor τρέξε:

```sql
update public.profiles set role = 'admin' where email = 'το-email-σου@example.com';
```

3. Ξαναμπές. Από τη σελίδα **Χρήστες** βλέπεις όλους.

Αν θέλεις να έχεις και δικούς σου μαθητές, χρειάζεσαι λογαριασμό εκπαιδευτικού. Ο διαχειριστής βλέπει και διαχειρίζεται όλους τους μαθητές. Για καθημερινή χρήση κάνε εγγραφή ως εκπαιδευτικός με άλλο email.

### 3. GitHub Pages

1. Φτιάξε repository στο GitHub και ανέβασε όλα τα αρχεία.
2. **Settings > Pages > Source:** διάλεξε *GitHub Actions*.
3. Κάθε push στο `main` τρέχει πρώτα τους ελέγχους. Αν βρουν πρόβλημα, δεν γίνεται deploy.

## Πώς συνδέονται μαθητές, γονείς και βοηθοί

1. Ο εκπαιδευτικός ανοίγει τον μαθητή και γράφει ένα email στο «Πρόσβαση». Διαλέγει σχέση: μαθητής, γονέας ή βοηθός.
2. **Αν το email έχει ήδη λογαριασμό**, η σύνδεση γίνεται αμέσως.
3. **Αν δεν έχει**, μένει πρόσκληση σε αναμονή. Συνδέεται μόλις ο άνθρωπος εγγραφεί με το ίδιο email.

Ο βοηθός πρέπει να έχει λογαριασμό **εκπαιδευτικού**. Αν εγγραφεί ως «Μαθητής ή γονέας», η πρόσκληση βοηθού μένει σε αναμονή.

Ένας γονέας με δύο παιδιά σε δύο εκπαιδευτικούς έχει έναν λογαριασμό και βλέπει και τα δύο παιδιά.

## Ποιος βλέπει τι

| Σχέση | Βλέπει | Αλλάζει |
|---|---|---|
| Διαχειριστής | Όλα | Όλα |
| Εκπαιδευτικός, για τους δικούς του μαθητές | Μαθητές, μαθήματα, σημειώσεις | Όλα τα δικά του |
| Εκπαιδευτικός ως βοηθός | Τον μαθητή και τα μαθήματά του | Τίποτα (μόνο το προσωπικό του ημερολόγιο) |
| Μαθητής | Τα δικά του μαθήματα | Μόνο το προσωπικό του ημερολόγιο |
| Γονέας | Τα μαθήματα του παιδιού του | Μόνο το προσωπικό του ημερολόγιο |

Οι ιδιωτικές σημειώσεις του εκπαιδευτικού για τον μαθητή τις βλέπει μόνο ο ίδιος και ο διαχειριστής. Δεν τις βλέπουν ο μαθητής, οι γονείς και οι βοηθοί.

Τους κανόνες τους επιβάλλει η βάση (RLS), όχι η σελίδα. Ακόμα κι αν κάποιος πειράξει τον κώδικα στον browser, δεν βλέπει ξένα δεδομένα.

## Αναβάθμιση υπάρχουσας βάσης

Το `supabase/schema.sql` τρέχει με ασφάλεια πάνω σε βάση που υπάρχει ήδη. Μετατρέπει τους παλιούς ρόλους (`main_teacher` και `assistant_teacher` σε `teacher`, `parent` και `pending` σε `student`) και μεταφέρει τις σημειώσεις στον νέο ιδιωτικό πίνακα.

## Έλεγχοι πριν από κάθε αλλαγή

```
npm run check
```

Ελέγχει σύνταξη, id στοιχείων HTML που δεν υπάρχουν και στήλες βάσης που δεν υπάρχουν στο `schema.sql`. Μηδέν ευρήματα ή διόρθωση. Ποτέ απόκρυψη του ευρήματος.

Οι έλεγχοι είναι στατικοί. Δεν πιάνουν λάθος λογική. Δοκίμασε με κάθε ρόλο πριν δώσεις τη σελίδα σε μαθητές.
