# Πλατφόρμα εξ αποστάσεως ιδιαιτέρων

Στατική ιστοσελίδα (GitHub Pages) με βάση δεδομένων και είσοδο χρηστών στο Supabase.

## Ρόλοι

- **Διαχειριστής**: εγκρίνει εκπαιδευτικούς, βλέπει και διαχειρίζεται τα πάντα.
- **Εκπαιδευτικός**: χρειάζεται έγκριση. Βλέπει μόνο τους δικούς του μαθητές και τους γονείς τους.
- **Μαθητής / γονέας**: ένας τύπος λογαριασμού. Βλέπει μόνο ό,τι αφορά τον ίδιο ή το παιδί του.
- **Γονέας και βοηθός δεν είναι τύποι λογαριασμού.** Είναι σχέσεις ανά μαθητή. Ένας εκπαιδευτικός έχει δικούς του μαθητές και ταυτόχρονα μπορεί να είναι βοηθός σε μαθητές άλλου.

## Τι κάνει

1. **Έγκριση εκπαιδευτικού.** Ο εκπαιδευτικός κάνει εγγραφή, συμπληρώνει αίτηση και ανεβάζει πτυχία (PDF, JPG, PNG, έως 5 MB). Ο διαχειριστής εγκρίνει ή απορρίπτει με σημείωση.
2. **Κατάλογος εκπαιδευτικών.** Οι εγκεκριμένοι εκπαιδευτικοί φαίνονται σε όλους. Οι γονείς στέλνουν αίτημα συνεργασίας και ο εκπαιδευτικός το δέχεται ή το απορρίπτει.
3. **Συνεργάτες.** Ο εκπαιδευτικός προσκαλεί άλλους εγκεκριμένους εκπαιδευτικούς. Μόνο οι συνεργάτες μπορούν να γίνουν βοηθοί.
4. **Μαθητές.** Ο εκπαιδευτικός προσθέτει μαθητές και τους συνδέει με email με τον μαθητή, τους γονείς και τους βοηθούς. Έχει και ιδιωτικές σημειώσεις που δεν τις βλέπει κανείς άλλος.
5. **Ομαδικά μαθήματα.** Ένα μάθημα έχει έναν ή περισσότερους μαθητές. Η παρουσία (προγραμματισμένο, πραγματοποιήθηκε, απουσία, ακυρώθηκε) ορίζεται ξεχωριστά για τον καθένα.
6. **Ώρες υποστήριξης.** Ο εκπαιδευτικός αναθέτει στον βοηθό δική του ώρα για συγκεκριμένους μαθητές. Μετριέται ξεχωριστά.
7. **Ημερολόγιο = παρουσιολόγιο**, με σύνοψη ωρών ανά μαθητή και ανά βοηθό. Ο καθένας βλέπει μόνο ό,τι τον αφορά.
8. **Δωμάτιο σύγχρονης διδασκαλίας.** Κάθε εκπαιδευτικός βάζει τον σύνδεσμο του δωματίου που θέλει (Meet, Zoom, Jitsi, Teams κ.λπ.). Όλοι μπαίνουν με το κουμπί «Σύνδεση», που ανοίγει νέο παράθυρο. Ένα μάθημα μπορεί προαιρετικά να έχει δικό του σύνδεσμο.
9. **Προσωπικό ημερολόγιο** για κάθε χρήστη.

Επόμενη φάση: σημειώσεις στο cloud και H5P.

## Ρύθμιση

### 1. Supabase

1. Στο Supabase άνοιξε **SQL Editor**.
2. Τρέξε **μία φορά** το `supabase/reset.sql`. Σβήνει τους παλιούς πίνακες. Να το τρέξεις μόνο όσο δεν υπάρχουν πραγματικά δεδομένα.
3. Τρέξε ολόκληρο το `supabase/schema.sql`. Μπορείς να το ξανατρέξεις όποτε θέλεις χωρίς πρόβλημα.
4. Στο **Storage** έλεγξε ότι υπάρχει ιδιωτικό bucket `credentials` (το δημιουργεί το schema).
5. Στο **Authentication → URL Configuration** βάλε ως Site URL τη διεύθυνση της σελίδας σου στο GitHub Pages.

### 2. Πρώτος διαχειριστής

Κάνε εγγραφή στη σελίδα και μετά στο SQL Editor τρέξε:

```sql
update public.profiles set role = 'admin' where email = 'το-email-σου';
```

Αυτό δουλεύει μόνο από το SQL Editor. Από τη σελίδα κανείς δεν μπορεί να αλλάξει τον δικό του ρόλο.

### 3. Σύνδεση της σελίδας

Το `js/config.js` έχει το URL του project και το publishable (anon) key. Το key είναι δημόσιο από σχεδίασμα. Την προστασία την κάνουν οι κανόνες RLS στη βάση, όχι το κλειδί.

### 4. GitHub Pages

Settings → Pages → Source: **GitHub Actions**. Το workflow τρέχει πρώτα τους ελέγχους και μετά δημοσιεύει.

## Απόρρητο και πιστοποιητικά

- Τα πτυχία είναι προσωπικά δεδομένα. Τα βλέπουν μόνο ο ίδιος ο εκπαιδευτικός και ο διαχειριστής, με προσωρινούς συνδέσμους διάρκειας 1 ώρας.
- Ο διαχειριστής είναι υπεύθυνος για τη σωστή χρήση τους (ΓΚΠΔ). Να σβήνονται όταν δεν χρειάζονται πια.
- Τα email δεν εμφανίζονται σε άλλους χρήστες. Οι κατάλογοι δείχνουν μόνο ονόματα.
- Οι ιδιωτικές σημειώσεις του εκπαιδευτικού είναι σε ξεχωριστό πίνακα, ώστε να μην τις δει ούτε ο μαθητής, ούτε ο γονέας, ούτε ο βοηθός.

## Έλεγχοι

```
npm run check
```

Ελέγχει σύνταξη, στοιχεία HTML που δεν υπάρχουν, στήλες και πίνακες που δεν υπάρχουν στο `schema.sql`, και ονόματα και παραμέτρους των `rpc`.

Τεστ κανόνων πρόσβασης (χρειάζεται τοπική PostgreSQL 16):

```
bash tools/db-test/run.sh
```

## Αρχεία

- `index.html`, `css/style.css`
- `js/core.js`: κοινά βοηθητικά και σύνδεση με το Supabase

- `js/page-people.js`: μαθητές, συνεργάτες, αιτήματα
- `js/page-lessons.js`: αρχική, δωμάτιο, ημερολόγιο, ώρες υποστήριξης, προσωπικό ημερολόγιο
- `js/app.js`: δρομολόγηση και εκκίνηση
- `supabase/schema.sql`, `supabase/reset.sql`
- `tools/check.js`, `tools/db-test/`
